Use your own Claude API key

Outside of Claude, Practice Room can still read notes from PDFs and photos and answer questions if you give it an Anthropic API key. Get one at console.anthropic.com. Usage is billed to your Anthropic account. Reading a page of music costs roughly a few cents to a quarter.

The key is stored only in this browser on this device and is sent only to Anthropic.
